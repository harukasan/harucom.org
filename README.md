# harucom.org

Source code for [harucom.org](https://harucom.org), built with Jekyll and deployed to GitHub Pages.

## Development

```
bundle install
script/fetch-firmware.sh   # downloads the firmware that /flash/ writes
bundle exec jekyll serve
```

`script/fetch-firmware.sh` pulls the latest Harucom OS release into
`assets/firmware/` and writes `_data/firmware.yml`. Both are ignored by git and
are regenerated by the Pages workflow on every build, so they never need to be
committed. Without them `/flash/` still works, but only with a UF2 file picked
from your own computer.
