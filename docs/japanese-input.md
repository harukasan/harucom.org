Harucom は日本語入力に対応しています。IRB のプロンプトでも、`edit` で開いたテキストエディタでも、
そのまま日本語を打ち込めます。

入力方式は2つあります。

- **SKK** — ローマ字でかなを入力し、漢字に変換する方式です。ふだんはこちらを使います。
- **T-Code** — 2打鍵の組み合わせで漢字を直接入力する方式です。

## 入力方式を切り替える

| キー | 動作 |
|------|------|
| <kbd><kbd>Ctrl</kbd>-<kbd>J</kbd></kbd> | SKK をオンにする（ひらがなモード）。ひらがなモードで押すとオフになる |
| <kbd><kbd>Ctrl</kbd>-<kbd>\\</kbd></kbd> | 入力方式を順番に切り替える（オフ → SKK → T-Code → オフ） |
| <kbd>半角/全角</kbd> | SKK のオン・オフを切り替える（JIS キーボードのみ） |
| <kbd>カタカナ/ひらがな</kbd> | ひらがな → カタカナ → 全角英字 の順に切り替える（JIS キーボードのみ） |

日本語入力がオンになっていると、画面のいちばん下に現在のモードが表示されます。

| 表示 | モード |
|------|--------|
| `[あ]` | ひらがな |
| `[ア]` | カタカナ |
| `[Ａ]` | 全角英字 |
| `[漢]` | T-Code |

表示が出ていないときは、ふだんどおりの英字入力です。

> <kbd>半角/全角</kbd> と <kbd>カタカナ/ひらがな</kbd> は JIS キーボードにしかありません。
> US キーボードを使っている場合は <kbd><kbd>Ctrl</kbd>-<kbd>J</kbd></kbd> で切り替えてください。
> キーボードの配列は [設定](../settings/) で変更できます。
{: .tip}

## SKK で日本語を入力する

<kbd><kbd>Ctrl</kbd>-<kbd>J</kbd></kbd> を押すと `[あ]` と表示され、ひらがなモードになります。

### かなを入力する

ローマ字を打つと、その場でかなに変わります。

```
nihongo   →  にほんご
kya       →  きゃ
nn        →  ん
```

かなモードでは次のキーが使えます。

| キー | 動作 |
|------|------|
| <kbd>q</kbd> | ひらがな と カタカナ を切り替える |
| <kbd>l</kbd> | 日本語入力をオフにして英字入力に戻る |
| <kbd>L</kbd> | 全角英字モードに切り替える |
| <kbd>Backspace</kbd> | 入力中のローマ字を1文字消す |

### 漢字に変換する

変換したい言葉の**先頭を大文字**で打つと、変換の準備が始まります。
画面には `▽` が付いた読みが表示されます。

```
Nihongo   →  ▽にほんご
```

読みを打ち終わったら <kbd>Space</kbd> を押して変換します。
変換中は `▼` が付き、画面の下に候補の一覧が表示されます。

| キー | 動作 |
|------|------|
| <kbd>Space</kbd> | 次の候補を表示する |
| <kbd>x</kbd> | 前の候補に戻る（先頭で押すと読みの入力に戻る） |
| <kbd>Enter</kbd> | 表示されている候補で確定する |
| <kbd>Esc</kbd> または <kbd><kbd>Ctrl</kbd>-<kbd>G</kbd></kbd> | 変換をやめて読みの入力に戻る |

候補を選んだあと、そのまま次の文字を打つと候補が確定して入力が続きます。

`▽` の状態で <kbd>Enter</kbd> を押すと、変換せずに読みのまま確定します。

### 送り仮名のある言葉を変換する

送り仮名が付く言葉は、送り仮名の**始まりを大文字**で打ちます。
大文字を打った時点で変換が始まるので、<kbd>Space</kbd> を押す必要はありません。

```
Ugo       →  ▽うご
K         →  ▼動*k     （ここで変換が始まる）
u         →  動く       （送り仮名が決まって確定する）
```

### 辞書にない言葉を登録する

変換しても候補が見つからないときは、単語登録モードになります。
画面には `[登録: よみ]` と表示されるので、登録したい言葉を入力して <kbd>Enter</kbd> を押します。

```
[登録: はるこむ] Harucom
```

登録した言葉はすぐに使えるようになり、`/data/skk-user-dict.txt` に保存されます。
電源を切っても消えません。

登録をやめるときは <kbd>Esc</kbd> か <kbd><kbd>Ctrl</kbd>-<kbd>G</kbd></kbd> を押します。

## T-Code で漢字を入力する

T-Code は2打鍵の組み合わせで漢字を直接入力する方式です。かな漢字変換をしないので、
変換操作なしに文章を打てます。

<kbd><kbd>Ctrl</kbd>-<kbd>\\</kbd></kbd> を SKK の状態から押すと `[漢]` になり、T-Code に切り替わります。

2打鍵の入力は 0.5 秒以内に打つ必要があります。時間が過ぎると、1打鍵目はふつうの文字として確定します。
T-Code の表に載っていないキーは、そのまま文字として入力されます。
