Harucom の設定は `/etc/env.yml` というファイルにまとまっています。
キーボードの配列と、起動時の文字の大きさをここで変えられます。

## 設定ファイル

設定はエディタで編集します。

```ruby
irb> edit /etc/env.yml
```

```yaml
KEYBOARD_LAYOUT: us
CONSOLE_ZOOM: 1
```

| 設定 | 値 | 説明 |
|------|-----|------|
| `KEYBOARD_LAYOUT` | `us` / `jis` | キーボードの配列 |
| `CONSOLE_ZOOM` | `1` / `2` | 起動したときの文字の大きさ |

保存したら <kbd><kbd>Ctrl</kbd>-<kbd>Alt</kbd>-<kbd>Delete</kbd></kbd> で[再起動](../restart/)すると設定が反映されます。

このファイルの内容は、起動時に環境変数として読み込まれます。
プログラムからは `ENV` で参照できます。

```ruby
irb> ENV["KEYBOARD_LAYOUT"]
=> "us"
```

自分で決めた設定を書いておくこともできます。書いた内容はそのまま `ENV` に入ります。

> ファームウェアを更新すると、`/etc/env.yml` を含むシステムのファイルは初期状態に書き戻されます。
> 設定を変えていた場合は、更新のあとにもう一度設定し直してください。
{: .tip}

## キーボードの配列を変える

`KEYBOARD_LAYOUT` でキーボードの配列を選びます。

| 値 | 配列 |
|----|------|
| `us` | US 配列（英語キーボード） |
| `jis` | JIS 配列（日本語キーボード） |

日本語キーボードをつないだときに記号の位置がずれる場合は `jis` にしてください。
`jis` にすると <kbd>半角/全角</kbd> や <kbd>カタカナ/ひらがな</kbd> のキーが使えるようになり、
[日本語入力](../japanese-input/)の切り替えが手軽になります。

知らない名前を書いた場合は `us` として起動します。

## 画面をズームする

テキスト画面は2つの大きさを切り替えられます。
テレビにつないだときなど、文字が小さくて読みづらいときに使います。

| ズーム | 解像度 | 文字数 |
|--------|--------|--------|
| 1 | 640x480 | 106桁 x 37行 |
| 2 | 320x240（ピクセルを2倍に拡大） | 53桁 x 18行 |

IRB のプロンプトで <kbd><kbd>Ctrl</kbd>-<kbd>Shift</kbd>-<kbd>=</kbd></kbd> を押すと、その場で切り替わります。

`zoom` コマンドでも変えられます。

```ruby
irb> zoom
zoom 1 (106x37 characters)

irb> zoom 2

irb> zoom 1
```

起動したときの大きさは `/etc/env.yml` の `CONSOLE_ZOOM` で決まります。
`2` にしておくと、電源を入れた直後から大きな文字で表示されます。

> ズームを切り替えると画面はクリアされます。表示されていた内容は残りません。
{: .tip}

## ファイルシステムを初期化する

作ったファイルを消して、出荷したときの状態に戻すこともできます。
`/FORMAT` という名前のファイルを作ってから再起動してください。

```ruby
irb> touch /FORMAT
```

再起動するとフラッシュメモリがフォーマットされ、システムのファイルが書き直されます。

> 自分で作ったファイルはすべて消えます。残しておきたいファイルがある場合は、
> 初期化する前に内容を控えておいてください。
{: .tip}
